MP2 Monitor V2 PWA

Upload the contents of this folder to the ROOT of your GitHub Pages repository (index.html, manifest.webmanifest, sw.js, and icons/). Enable GitHub Pages for the branch/root. Open the HTTPS Pages URL in Chrome on Android and choose Install app / Add to Home screen.

Keep the same site origin and path to preserve existing IndexedDB data. A file:// HTML page and a GitHub Pages site have separate storage. Export JSON from the old app and import into the hosted PWA if moving origins.

The standalone HTML can also be opened directly, but PWA installation/offline service worker requires HTTPS or localhost.
